# Flagship direction

Build a defensible derivatives-risk research application connecting classical scenario methods to explicit quantum estimation costs.

Read src/studio.py, docs/study.json and reports/applied-study.md before adding features. Extend the applied application and its usable interface. Preserve legacy public APIs.

## Next priorities

- Calibrate multi-asset scenarios from a user-supplied price CSV and compare model risk under non-Gaussian returns.
- Map a bounded positive-exposure payoff into the oracle and separate discretization, truncation and estimation errors.
- Measure amplitude-estimator bias and interval coverage across independent trials, including boundary probabilities.

Every milestone must answer a substantive applied question, compare a meaningful baseline, measure actual results and expose the result in the existing studio when relevant. Avoid isolated textbook scripts. Preserve negative findings. Keep artifacts compact and dependencies pinned; no API keys, extra agents or model sessions.
