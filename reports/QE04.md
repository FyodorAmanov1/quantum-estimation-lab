# QE04: Bounded exposure oracle

## Question

For the existing four-contract option book, how much of a bounded oracle's
mean-exposure error comes from capping, grid rounding and amplitude estimation?
Does increasing the exposure cap necessarily improve the approximation when
the register size is fixed? Compare Gaussian GBM with the already specified
common variance mixture, holding fitted parameters and pricing inputs fixed.

## Method

Use the existing CSV-calibrated four-asset book: units [50, -30, 40, 20],
call/put/call/put, strikes [100, 85, 115, 65], initial maturity 0.5 years,
horizon 21/252 years and rate 3%. Future Black-Scholes values use the same
fitted historical volatility proxy as the preceding studies. The bundled
price history is generated synthetic data, with cutoff 2025-12-31; user CSVs
and explicit cutoffs also flow into this experiment. Full fitted parameters,
input fingerprint and dates are recorded without exporting the local CSV path.

For each model, evaluate 32768 book paths at seed 1729. GBM uses scrambled
Sobol normals. The mixture uses those normals plus independent pseudorandom
regimes, as in QE03. Let X=max(future net book value,0), in undiscounted USD.
This is exposure after netting the four positions, not a sum of individually
positive contract values. Its expectation is distinct from PFE (a quantile),
VaR (a loss quantile) and CVA (which requires additional default assumptions).

Define Y=min(X,C) and nodes g_j=C*j/(L-1), j=0,...,L-1. Round Y down to G,
the largest node not exceeding it. Histogram frequencies p_j define a finite
empirical exposure law; zero and the cap atom are retained. Defaults C=400 USD
and L=32 use five register qubits plus one ancilla. The existing Householder
oracle prepares amplitudes sqrt(p_j*(1-g_j/C)) and sqrt(p_j*g_j/C). Its good
probability a=sum(p_j*g_j/C), so the exact encoded expectation is C*a.
This is a payoff grid, not a tensor grid of four continuous asset prices.

For an amplitude estimate a_hat, the following signed identity holds on the
same scenario sample, with no simulated population truth assumed:

```text
C*a_hat - mean(X)
  = [mean(Y)-mean(X)] + [mean(G)-mean(Y)] + [C*a_hat-mean(G)].
       truncation             grid                  estimation
```

Truncation equals -mean((X-C)+), and grid error lies in [-C/(L-1),0]. The
latter follows pointwise from 0 <= Y-G <= C/(L-1), and therefore also holds
for a population expectation. Empirical tail excess does not bound the
unobserved population tail. The code exports both signed components and the
tail excess as an independent reconstruction. Nine cap/grid combinations
(C=200/400/800, L=16/32/64) use the same revalued scenarios.

The existing maximum-likelihood amplitude estimator uses powers 0,1,2,4,8,
256 shots each and measurement seed 1729. It searches 32769 theta points;
reported estimation error includes shot randomness and this numerical search.
Its profile-likelihood bounding interval uses the existing asymptotic cutoff,
can span disconnected sets, and is conditional on this encoded law only.
See [Suzuki et al.](https://arxiv.org/abs/1904.10246) for algorithmic background;
[Woerner and Egger](https://arxiv.org/abs/1806.06893) discuss financial-function
amplitude encodings. These citations do not validate the approximations here.

Classical baselines are the exact histogram expectation, direct sampling of
grid node values and a Bernoulli observation with probability a, each sampled
baseline using 8960 independent draws from the encoded law. The baseline RNG
uses SeedSequence(1729, spawn_key=(404,)), Bernoulli then grid draws. Direct
grid sampling retains the observed payoff rather than adding ancilla noise;
its sample standard error is reported. One recorded trial per model cannot
establish comparative estimator bias, RMSE or coverage.

Twelve separately scrambled scenario constructions at seeds 100-111 record
raw, capped and grid means. A separate 131072-path seed-499 mean is a numerical
reference, not an exact answer. Its difference from the display sample is a
fourth component when comparing against that reference. The twelve-run raw
mean SD describes variability of scenario construction, not measurement
uncertainty or historical parameter/model error. The mixture regime draws
remain pseudorandom even though its normal draws are Sobol.

## Reproduce

With the pinned requirements, run from the repository root:

```text
python -m unittest discover -s tests -v
python lab.py --output results/latest.json
python src/studio.py --out docs/study.json
python src/studio.py --check docs/study.json
```

Select **Bounded exposure oracle** in the existing studio or use the
`#bounded-exposure` fragment. The case exposes the signed error budget,
cap/grid sensitivity, classical comparison and limitations. The full JSON
export contains nodes, counts, probabilities, replicate means and query costs.
To use a synchronized adjusted price CSV with assets A-D:

```text

```

## Actual findings

All values below are USD from the bundled synthetic fixture, rounded from
[lab results](../results/latest.json) and [studio data](../docs/study.json).

| Quantity | GBM | Variance mixture |
| --- | ---: | ---: |
| Empirical uncapped mean | 145.680968 | 146.792906 |
| Capped mean | 145.508447 | 145.428805 |
| Exact encoded grid mean | 139.666945 | 139.552750 |
| Amplitude estimate | 138.503126 | 138.338937 |
| Truncation error | -0.172520 | -1.364102 |
| Grid error | -5.841502 | -5.876055 |
| Amplitude-estimation error | -1.163819 | -1.213813 |
| Total error versus empirical mean | -7.177841 | -8.453969 |
| Direct grid sample estimate | 139.444124 | 139.318836 |
| Direct grid sample standard error | 1.004117 | 0.952670 |
| Bernoulli sample estimate | 139.419643 | 139.330357 |
| Independent reference mean | 145.679141 | 146.545068 |
| Empirical minus reference | +0.001827 | +0.247838 |
| Raw mean SD across twelve scenario runs | 0.006730 | 0.142303 |

Grid rounding dominates the default approximation error. The cap affects
0.5859% of GBM scenarios and 1.3519% of mixture scenarios. Capping removes
enough mixture tail exposure to reverse the ordering of capped and grid means
relative to the raw means. This is an approximation effect, not a discovery
about which model is safer.

Increasing the GBM cap from 400 to 800 USD with 32 levels eliminates observed
cap loss but increases grid loss from 5.8415 to 11.6722 USD. At 400 USD,
increasing the grid to 64 levels reduces grid loss to 2.8672 USD. A 200 USD
cap instead loses 18.6915 USD to truncation before rounding. Thus more shots
cannot repair a poorly chosen cap or grid, and raising the cap alone need
not improve total approximation error.

The conditional likelihood intervals are [137.300144,139.653725] for GBM and
[137.154498,139.507495] for the mixture. Both miss their exact encoded grid
means in these trials. Neither interval targets the uncapped exposure mean.
The amplitude estimates also have greater absolute grid-target errors than
both sampled classical baselines. Retain these negative findings; two trials
do not measure coverage or prove a general estimator ranking.

## Costs and limitations

The exposure study evaluates 1114112 book paths and 4456448 future option
values, plus 28 initial book valuations. These counts cover two models, each
with one display sample, twelve scenario replicates and one larger reference.
Cap/grid sweeps reuse those values. Histogramming costs O(paths) per grid;
its 32-bin exact expectation is already available classically.

Each default oracle is a dense 64-by-64 CPU matrix with six logical qubits.
There are 1280 measured shots and sum_k 256*(2*k+1)=8960 preparation-or-inverse
calls per model. These are logical accounting units, not device gate counts
or timings. They omit classical scenario/repricing work, memory, matrix
construction, inference, hardware noise, compilation and loading costs.
The histogram is an empirical compression requiring the answer-bearing
classical values first. No efficient coherent scenario/repricing circuit,
fault-tolerant resource estimate or quantum advantage is demonstrated.

No market observations, physical-probability calibration, default process,
collateral, transaction costs or implied volatility surface are supplied.
Population truncation error, out-of-sample accuracy and parameter uncertainty
are unmeasured. The reference and scramble SDs cannot quantify those omissions.
The specified mixture is a model sensitivity assumption, not fitted dynamics.

## What the author should understand for an interview

- Derive the three-term signed error identity and explain why it uses the same
  scenario sample; identify the extra term when comparing with a reference.
- Distinguish the distribution-free grid bound from measured sample tail excess,
  and explain why larger caps can worsen fixed-register grid precision.
- Explain net positive future exposure, its USD normalization and cap/zero atoms;
  distinguish mean exposure from PFE, VaR and default-weighted credit loss.
- Reconstruct the good ancilla probability from exported counts and nodes, and
  derive the 2*k+1 preparation/inverse calls for a power-k measurement.
- Explain why the exact classical histogram baseline is decisive for this
  implementation, and what a coherent pricing oracle would still require.
- Interpret a missed conditional likelihood interval honestly and distinguish
  realized shot error, estimator coverage, scenario variation and model error.
