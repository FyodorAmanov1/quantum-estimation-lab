# QE06: Oracle compilation ledger

## Question

For the existing capped positive-exposure application, what gate operations
are hidden inside a preparation call, and what does finer exposure resolution
cost? Compare the amplitude schedule with power-zero sampling at the same
preparation/inverse-call budget, retaining the exact classical histogram mean
as the available baseline.

## Method

Reuse the calibrated four-option book, synthetic price fixture, 400 USD cap,
32 floor-rounded nodes and empirical GBM/variance-mixture laws from QE04.
The target is mean positive undiscounted future net value, not VaR, PFE or
credit loss. Classical scenario simulation, revaluation and histogram
construction precede compilation and already determine the encoded mean.
All previous error budgets and unfavorable individual trials remain.

Construct a binary probability tree for the joint probabilities
`p_j*(1-f_j), p_j*f_j`. At each node use rotation angle
`2*atan2(sqrt(right mass), sqrt(left mass))`, choosing zero for a zero-mass
branch. Compile each level's multiplexed Ry using a cyclic binary Gray code
and an inverse Walsh transform of its branch angles. Qubit zero is most
significant and the final qubit is the payoff ancilla. JSON exports contain
every gate, target, control and rotation angle. The inverse reverses the gate
list and negates all Ry angles. The construction follows uniformly controlled
rotations from [Mottonen et al.](https://arxiv.org/abs/quant-ph/0407010),
specialized to a real nonnegative state.

For L nodes, n=log2(2L) data qubits, the unpruned circuit contains
2L-1 Ry and 2L-2 CNOT gates. Count emitted gates, including zero angles and
closing Gray-cycle CNOTs. No cross-block cancellation or connectivity routing
is applied. The resulting A differs from the dense Householder matrix away
from its first column. However, `A S0 A^-1 = I - 2|state><state|`, so the
same prepared state gives the same Grover operator.

Use `Q=-A S0 A^-1 Sgood`, applied in time order Sgood, inverse A, S0, A.
Sgood is Z on the payoff ancilla. S0 flips the phase only on the all-zero
data state: apply X on each data qubit, compute an AND of the first n-1
data qubits into n-2 clean work qubits, apply CZ between the final AND and
last data qubit, uncompute the ladder and apply X again. For n=6 this is
12 X, 8 CCX and 1 CZ, with four reusable clean work qubits. Tests replay
the reflection on every basis input for n=2 through 6, checking its phase
and clean workspace. Controlled-gate background:
[Barenco et al.](https://arxiv.org/abs/quant-ph/9503016).

The gate set is explicitly mixed-level: Ry, CNOT, X, Z, CZ and CCX (Toffoli).
CCX remains a three-qubit primitive. No decomposition into Clifford+T or
elementary two-qubit gates is assumed. Ry angles have ideal real precision.
The global minus in Q is irrelevant for these uncontrolled powers and
measurements. There are no controlled-A or controlled-Q calls.

For N shots at power k, count N*(k+1) A, N*k inverse A and N*k of
each reflection. These are serial logical operation inventories. Each shot
starts from zero and includes its own initial preparation. Reset, readout,
classical inference, rotation synthesis, error correction and runtime costs
are excluded; shot counts and peak qubits are reported separately.

## Actual findings

Both empirical 32-node laws compile to 63 Ry and 62 CNOT gates per A.
They use six data qubits; reflection adds four clean reusable work qubits,
giving ten peak qubits. The amplitude schedule is unchanged: powers
0,1,2,4,8 with 256 shots per power, or 1,280 measured shots.

| --- | ---: | ---: |
| Measured shots | 1,280 | 8,960 |
| Forward A | 5,120 | 8,960 |
| Inverse A | 3,840 | 0 |
| Grover iterations | 3,840 | 0 |
| Ry | 564,480 | 564,480 |
| CNOT | 555,520 | 555,520 |
| X | 46,080 | 0 |
| Z | 3,840 | 0 |
| CZ | 3,840 | 0 |
| CCX | 30,720 | 0 |

The equal-call baseline uses the same compiled A but measures at power zero.
It has identical preparation-gate totals and avoids all reflection gates;
equal calls do not mean equal gate inventories, shots or runtime. Direct
classical histogram summation needs no quantum gates or measurement error
and already knows the mean. These counts supply no advantage evidence.

Maximum absolute state errors against dense preparation are 2.22e-16 (GBM)
and 1.39e-16 (mixture). Reversing the emitted circuit on all unitary columns
has maximum errors 4.75e-16 and 6.66e-16. Grover matrix differences are
8.88e-16 and 1.33e-15. Across all five powers, success-probability differences
are at most 6.44e-15. These are numerical equivalence checks, not physical
gate-error estimates.

| GBM nodes, cap 400 USD | Signed grid error / USD | Ry per A | CNOT per A | Peak qubits |
| --- | ---: | ---: | ---: | ---: |
| 16 | -11.954574 | 31 | 30 | 8 |

Grid errors reuse actual option-book scenarios from QE04. Unpruned counts
depend only on shape, so sizing laws suffice for those three counts; both
main 32-node circuits use the actual empirical probabilities. Increasing
16 to 64 nodes reduces floor-grid loss by about 9.09 USD while multiplying
Ry count by about 4.10. This is an approximation/circuit-size tradeoff,
not an optimization or population error bound.

## Limitations

This compiles a precomputed empirical histogram, not coherent market-data
loading, correlated scenarios or Black-Scholes arithmetic. Classical
preprocessing and exact histogram knowledge prevent an end-to-end speedup
inference. The ledger is an explicit unoptimized construction, not a lower
bound or the resource count of the dense Householder implementation. CCX
decomposition, finite-precision synthesis, connectivity, noise, reset and
hardware execution remain unmeasured. Controlled powers need a new ledger.

Synthetic prices, historical-volatility pricing, cap, finite grid, scenario
uncertainty and specified mixture assumptions retain earlier limitations.
Conditional estimator coverage from QE05 does not cover those errors.
There is no claim of market accuracy, novelty or quantum advantage.

## What the author should understand for an interview

Explain why the empirical histogram already gives the classical answer, and
why compiling it still helps audit oracle assumptions. Derive the k+1 versus
k preparation split; distinguish controlled gates inside A from controlled-A
queries (none here). Explain why unitaries with the same first column give
the same reflected state but are different full unitaries. Walk through
the clean AND ladder and uncomputation. Distinguish six data qubits from ten
peak qubits, exact real rotations from synthesized ones, and CCX counts
from elementary two-qubit totals. Explain why lowering floor error increases
preparation size without proving a hardware advantage.
